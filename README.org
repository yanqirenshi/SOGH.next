* インストール

#+begin_src bash
npm install sogh
#+end_src

次のパッケージは peerDependencies です。アプリ側でインストールしてください。(アプリが使っている MUI をそのまま使うため、sogh は MUI を同梱しません)

| パッケージ                                 | 範囲                                            | 動作を確かめた版                 |
|--------------------------------------------+-------------------------------------------------+----------------------------------|
| react / react-dom                          | ^18.0.0 \|\| ^19.0.0                            | 18.3.1 / 19.3.1                  |
| @mui/material / @mui/icons-material        | ^5.14.20 \|\| ^6.0.0 \|\| ^7.0.0 \|\| ^9.0.0       | 5.18.0 / 6.5.0 / 7.3.11 / 9.5.0  |
| @emotion/react / @emotion/styled           | ^11.10.4                                        | 11.14                            |

#+begin_src bash
npm install react react-dom @mui/material @mui/icons-material @emotion/react @emotion/styled
#+end_src

MUI を使っているアプリは、すでに入っているので、追加は要りません。アプリの ThemeProvider のテーマが、そのまま使われます。
(@mui/lab と @mui/x-date-pickers は、使っていないので、要りません)
